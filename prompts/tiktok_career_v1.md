# 【TikTok向け 転職ノウハウ/実用コンテンツ投稿プロンプト v2.0】

## 1. 目的
TikTokで「保存」「コメント」「共感」を最大限引き出す、**転職・就活に役立つ実用的なノウハウ・気づき**を、1〜2枚のスクリーンショットに収まる形で伝える投稿の作成。
**個人の体験談・エピソード形式ではなく、読者にとって役立つ情報・リスト・ノウハウとして提示すること。**

## 2. コンテンツパターン（今回指定されたものを使うこと）

### パターン1：転職失敗談あるある
転職・退職でよくある「後悔ポイント」を、複数列挙する形で紹介する。
- 「〇〇せずに転職して後悔した話、あるあるすぎる」のような導入
- 具体的な後悔ポイントを2〜3個、箇条書き的に(改行を使って)並べる
- 例：「転職前に有給消化の交渉をしなかった」「退職理由を正直に話しすぎた」「年収交渉を一切しなかった」等

### パターン2：入社しない方がいい会社の特徴◯選
「こういう会社は要注意」という、企業選びで見るべきチェックポイントをリスト形式で紹介する。
- 「入社前に絶対チェックすべき会社の特徴3選」のような導入
- 具体的な特徴を2〜4個、番号付きで列挙する
- 例：「①面接官が終始不機嫌」「②離職率を聞いてはぐらかす」「③残業代の計算方法が曖昧」

### パターン3：面接でのNGな切り返し→こう言えば良かった
面接でありがちな「悪い回答例」と「良い回答例」を対比させて紹介する。
- 「面接でこう答えるのはNG、代わりにこう言おう」のような導入
- 質問に対する「NG例」と「OK例」をセットで1〜2個紹介する
- 例：「退職理由を聞かれて『人間関係が悪くて』はNG。『新しい環境で〇〇に挑戦したくて』と言い換えるのがベター」

### パターン4：面接官が即採用したくなる回答例
特定の質問に対する「模範解答」を、具体例とともに紹介する。
- 「この質問にこう答えられたら一発内定レベル」のような導入
- 具体的な質問と、模範解答例を1〜2セット紹介する
- 例：「『弊社を選んだ理由は？』と聞かれたら、企業の強みを引用しつつ自分の経験と結びつけて答えるのが効果的」

## 3. 避けるべき要素
・犯罪的な行為 / 過度な誹謗中傷 / 明らかな差別表現 / 露骨な営業・宣伝 / 単なる愚痴 / 過度に攻撃的な内容
・実在の企業名・個人名を出さない（一般化した表現にする）
・**個人の一人称の体験談・エピソード形式にしないこと（「私は〇〇でした」という物語ではなく、「〇〇な人は要注意」「〇〇と答えるのがベター」という、読者への実用的な情報提供の形にすること）**

## 4. 感情表現
・絵文字を適度に使用（1〜2個程度）
・主な感情絵文字例：😅😭🤔😮‍💨💭🥺💸✅❌
・絵文字は文末や感情表現の直後に配置

## 5. 文字数ルール（絶対厳守）
- **全体で320〜380文字程度に収めること。** 2枚のスクリーンショットに均等に収まる分量。
- **2ブロック構成にすること。** 1ブロックあたり160〜190文字程度で均等に分ける。
- ブロック間は必ず `=====` で区切ること。
- 1文（または1項目）ごとに改行し、話題の切り替わりごとに空白行を1行はさむこと。

## 6. タイトルのルール
- 17文字以内、句読点なしの体言止め、または短いフレーズ
- 「◯選」「あるある」「NG例」など、リスト・ノウハウ感が伝わるタイトルにする
- 例：「入社前に見るべき3点」「面接NG回答集」「転職失敗あるある」

## 7. 文章構成
1. 第1ブロック：導入＋前半の項目（何についてのリスト・ノウハウか提示し、1〜2項目を紹介）
2. 第2ブロック：残りの項目＋まとめ（最後に一言、読者への軽い問いかけを添えて締める）

## 8. ハッシュタグのルール
本文の最後に、内容に関連するハッシュタグを3個つけること（多すぎても少なすぎても不可）。
例：#転職 #転職ノウハウ #就活 #面接対策

## 9. 出力フォーマット（text/markdown形式で必ず出力｜考察などは不要なので本文のみを出力）

```
■(タイトルの実際の文字列。角括弧は使わない)

(第1ブロック。160〜190文字程度)

=====

(第2ブロック。160〜190文字程度)
（最後に内容に合った絵文字を1〜2個）

#タグ1 #タグ2 #タグ3
■(タイトル再掲。角括弧は使わない。ハッシュタグ行の直後に空白行を入れず、必ず次の行に続けて書くこと)
```

※出力全体をMarkdownのコードブロック（```で囲む）にしないこと。本文をそのまま出力すること。

## 10. 出力前の最終確認チェックリスト
- [ ] **個人の一人称エピソード（「私は〇〇でした」）になっていないか？実用的なノウハウ・リスト形式になっているか？**
- [ ] 指定されたパターンの型に沿っているか？
- [ ] 全体で320〜380文字程度に収まっているか？実際に文字数を数えたか？**短ければ、項目をもう1つ追加するか、各項目の説明を1文ずつ補足すること（削って調整するのではなく、必ず加筆で320文字以上に届かせる）**
- [ ] 2ブロックの文字数バランスは均等か？
- [ ] 実在の企業・個人が特定できる情報を含んでいないか？
- [ ] タイトルは体言止め・フックのある短いフレーズか？
- [ ] ハッシュタグはちょうど3個か？
- [ ] 区切り線(`=====`)が1つだけ含まれているか？

## 11. 分量・形式の目安（重要）
以下は「パターン2」の約370文字の例です。これより短くならないよう意識してください。**個人の体験談ではなく、このような実用リスト形式で書くことを徹底してください。**

```
■入社前に見るべき危険信号

転職活動中、この特徴がある会社は要注意です。

①面接官が終始不機嫌、または質問に曖昧にしか答えない
②「離職率は？」と聞くとはぐらかされる
③残業代の計算方法や有給消化率について、具体的な数字が出てこない

=====

④社員の平均勤続年数が極端に短い
⑤面接が1回だけで即日内定を出してくる（見極める気がない可能性）

これらは実際に「入ってから後悔した」という声が多い共通点です😮‍💨
1つでも当てはまったら、他の情報もしっかり調べてから決めることをおすすめします。

みなさんは面接で、どんなポイントをチェックしていますか？

#転職 #転職ノウハウ #就活 #ブラック企業
```

## 重要：出力に関する絶対禁止事項
- 文字数確認・自己チェックの結果・「✅」「❌」などのマーク・[info]や[note]のようなタグ・メタ情報を、出力に一切含めないこと。
- 出力は、実際にSNSへそのまま投稿される本文そのものである。チェックは内部で行い、その結果や過程を書き残さず、最終的な投稿本文だけを出力すること。
