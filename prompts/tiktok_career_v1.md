# 【TikTok向け 転職あるある/共感型投稿プロンプト v1.0】

## 1. 目的
TikTokで「保存」「コメント」「共感」を最大限引き出す、転職・仕事・職場をテーマにした、1〜2枚のスクリーンショットに収まる投稿の作成。

## 2. 投稿の要素
以下のいずれかのパターンを含む
・ブラック企業あるある（サービス残業、休日出勤、理不尽な評価制度など）
・転職して人生が変わった体験（年収アップ、労働環境の改善、後悔していること）
・「この業界はやめとけ」「この職種は狙い目」という業界・職種のリアルな声
・面接・退職・引き継ぎでの理不尽な体験
・上司・同僚との価値観の衝突
・給与・待遇に関する具体的な数字を伴う驚き（手取り〇〇万円→〇〇万円等）

## 3. 避けるべき要素
・犯罪的な行為 / 過度な誹謗中傷 / 明らかな差別表現 / 露骨な営業・宣伝 / 単なる愚痴 / 過度に攻撃的な内容
・実在の企業名・個人名を出さない（フィクションの創作エピソードとして書く。「大手〇〇業界」「都内の中小企業」のようなぼかした表現にする）
・具体的すぎる特定企業が分かる情報は避ける

## 4. 感情表現
・絵文字を適度に使用（1〜2個程度）
・主な感情絵文字例：😅😭🤔😮‍💨💭🥺💸
・絵文字は文末や感情表現の直後に配置

## 5. 文字数ルール（絶対厳守）
- **全体で320〜380文字程度に収めること。** 2枚のスクリーンショットに均等に収まる分量。
- **2ブロック構成にすること。** 1ブロックあたり160〜190文字程度で均等に分ける。
- ブロック間は必ず `=====` で区切ること。
- 1文ごとに改行し、話題の切り替わりごとに空白行を1行はさむこと。

## 6. タイトルのルール
- 17文字以内、句読点なしの体言止め、または短いフレーズ
- 内容が気になる・続きが読みたくなるフックのあるタイトルにする
- 例：「手取り18万の限界」「転職して知った現実」「この業界はマジで注意」

## 7. 文章構成
1. 第1ブロック：導入・状況説明（自分の当時の状況、具体的なエピソードの始まり）
2. 第2ブロック：展開・結び（感情の高まり、気づき、問いかけで締める）

## 8. ハッシュタグのルール
本文の最後に、内容に関連するハッシュタグを3個つけること（多すぎても少なすぎても不可）。
例：#転職 #ブラック企業 #社会人あるある

## 9. 出力フォーマット（text/markdown形式で必ず出力｜考察などは不要なので本文のみを出力）

```
■(タイトルの実際の文字列。角括弧は使わない)

(第1ブロック。160〜190文字程度)

=====

(第2ブロック。160〜190文字程度)
（最後に内容に合った絵文字を1〜2個）

#タグ1 #タグ2 #タグ3
■(タイトル再掲。角括弧は使わない。ハッシュタグ行の直後に空白行を入れず、必ず次の行に続けて書くこと)
```

※出力全体をMarkdownのコードブロック（```で囲む）にしないこと。本文をそのまま出力すること。

## 10. 出力前の最終確認チェックリスト
- [ ] 全体で320〜380文字程度に収まっているか？実際に文字数を数えたか？**短ければ、以下のいずれかを1〜2文追加すること（削って調整するのではなく、必ず加筆で320文字以上に届かせる）**
  - 当時の具体的な数字（残業時間、給与額、勤続年数など）を補足する一文
  - 周囲の人（同僚・家族）の反応やセリフを1つ追加する
  - その時の自分の心境をもう少し詳しく描写する一文
- [ ] 2ブロックの文字数バランスは均等か？
- [ ] 実在の企業・個人が特定できる情報を含んでいないか？
- [ ] タイトルは体言止め・フックのある短いフレーズか？
- [ ] ハッシュタグはちょうど3個か？
- [ ] 区切り線(`=====`)が1つだけ含まれているか？

## 10.5 文字数の目安（重要）
400字は、だいたい以下のボリューム感です。目安として意識してください。これより短くならないよう注意してください。

「新卒で入った会社、月の残業が80時間を超えているのに、手取りは18万円しかなかった。「若いうちの苦労は買ってでもしろ」と上司に言われ続け、そのまま3年間働き続けてしまった。有給を使おうとしたら「みんな我慢してるんだから」と却下されたこともある。=====限界を感じて転職活動を始めたところ、同じ業界でも給与水準がまったく違う会社がいくつも見つかった。今の会社は残業が月10時間以内で、手取りは24万円。家族にその話をしたら「なんでもっと早く辞めなかったの」と驚かれた。あの3年間、自分は一体何を我慢していたんだろうと今になって思う😮‍💨同じような状況の人、他にもいるのかな？」

（↑これで約380文字です。これより短くならないよう意識してください）

## 11. 分量の目安（重要）
以下は約350文字の例です。これより短くならないように意識してください。

```
■手取り18万の限界

新卒で入った会社、月の残業が80時間超えなのに手取りは18万円だった。

「若いうちの苦労は買ってでもしろ」って上司に言われて、3年間そのまま働き続けた。
有給を使おうとしたら「みんな我慢してるから」と却下された。

=====

限界を感じて転職活動を始めたら、同じ業界でも給与水準がまったく違う会社がゴロゴロあることを知った。

今の会社は残業月10時間以内で手取り24万円。
なんであの3年間、あんなに我慢してたんだろうと今は思う😮‍💨

同じような状況の人、他にもいるのかな？

#転職 #ブラック企業 #社会人あるある
```

## 重要：出力に関する絶対禁止事項
- 文字数確認・自己チェックの結果・「✅」「❌」などのマーク・[info]や[note]のようなタグ・メタ情報を、出力に一切含めないこと。
- 出力は、実際にSNSへそのまま投稿される本文そのものである。チェックは内部で行い、その結果や過程を書き残さず、最終的な投稿本文だけを出力すること。
