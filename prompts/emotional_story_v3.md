# 【バズ特化】涙を誘うストーリー生成・完全制約プロンプト v3.0

## 1. 目的
TikTok・Threadsで「保存」「拡散」「涙腺崩壊」を生む、リアリティと論理性を極めた感動ストーリーの作成。

## 2. 文字数・構成ルール（絶対遵守）
* **全体文字数：720文字前後（厳守）**
    * 800文字を超えるとスマホ1スクショに収まりません。徹底してください。
* **3ブロック均等構成（最重要）：**
    * 各ブロックを **240文字前後** に調整してください。
    * 極端な偏り（1ブロックだけ400文字など）は厳禁。
    * 1ブロック目：134文字、2ブロック目：147文字、3ブロック目：519文字のような不均等は絶対に避ける。
* **セパレーター：** ブロック間は必ず `=====` で区切ること。
* **各ブロック内の空白行：** 2〜3回程度入れて読みやすくすること。

## 3. 時系列・リアリティの二重検閲（最重要・致命傷を避ける）

### 【出力前必須チェック①：時系列の整合性】
⚠️ **時系列の破綻はストーリー全体を台無しにします。必ず以下を確認してください。**

#### ❌ 直近設定の禁止
* 「2週間前のこと」「先月のこと」「先週」は使用禁止
* これらの設定では物語に必要な時間経過（卒業、転勤、成長など）が成立しない

#### ⭕ 推奨される時間設定
* 「数年前の春」「2年前の夏」「ある日のこと」「半年ほど前」
* 物語に十分な時間的余裕を持たせる

#### 📋 出力前の必須チェックリスト
1. **冒頭で設定した時期を確認**
   - 例：「3年前の春」→ 3年間の物語が展開可能

2. **物語内の時間経過を計算**
   - 「5年生の秋」→「手術」→「復帰」→「卒業式」
   - この流れに必要な最低期間は？（約1年半）

3. **イベントの時期を逆算**
   - 卒業式は3月 → 手術から復帰まで数ヶ月必要 → 手術は遅くとも前年秋まで

4. **「〇〇年間ありがとう」の整合性**
   - 「3年前に出会った」→「3年間ありがとう」は正しい
   - 「1年前に出会った」→「3年間ありがとう」は矛盾

#### 具体例：時系列の正しい構築
✅ 正しい例：
「3年前の春、用務員になった」
→「当時4年生のたくみくん」
→「6年生の春に手術」
→「夏休み明けに復帰」
→「3月の卒業式」
→「3年間ありがとう」← 整合性あり

❌ 間違い例：
「1年前、用務員になった」
→「3年生のたくみくん」
→「ある日手術」
→「2ヶ月後復帰」
→「卒業式」← 時期が成立しない
→「3年間ありがとう」← 矛盾

### 【出力前必須チェック②：登場人物のリアリティ】
* **年齢・職業・経験年数の整合性：**
    * 22歳で「30年のベテラン」は不可
    * 大学生が「副操縦士」は不可（訓練生なら可）
    * 高校生が「会社員時代」の回想は不可
* **社会常識との照合：**
    * 日本の法律、資格制度、一般的なキャリアパスに反していないか
    * 医師・弁護士・パイロット等の専門職は特に注意

### 【時系列チェックの実施方法】
出力前に以下を自問自答してください：
1. 「この物語に必要な最小時間は？」
2. 「冒頭の時間設定で、その期間をカバーできるか？」
3. 「『〇年間』という表現と、実際の経過時間は一致しているか？」
4. 「季節や学年の進行は自然か？」
5. 「手術から復帰、復帰から卒業式などの間隔は現実的か？」

## 4. 主人公紹介の最適化（二重チェック必須）

### 【原則】
年齢・性別を機械的に述べるのではなく、**ストーリーに最も効果的な紹介方法**を選択する。

### 【判断基準】
* **年齢が重要な場合：** 「22歳の新人看護師」「還暦を過ぎてから始めた花屋」
* **経験が重要な場合：** 「この道15年、弁当屋を営んでいます」「30年のベテラン理髪師」
* **性別が重要でない場合：** 「街のパン屋を営んでいます」「図書館で司書をしています」
* **若さ/初々しさが重要：** 「大学を出たばかりの保育士」「働き始めて半年の会社員」
* **経緯が重要な場合：** 「父の跡を継いで町工場を営んでいます」

### 【出力前の自己質問】
1. 「この紹介方法で、読者は主人公を最もイメージしやすいか？」
2. 「年齢・性別・職歴・経験年数のうち、どれが感動に最も寄与するか？」
3. 「『私は26歳の男性で』という機械的な紹介より良い表現はないか？」

## 6. 表現の制約
* **「感動した」「泣けた」等の感情語は使用禁止**
    * 代わりに具体的な動作や情景で示す
    * ⭕「胸が熱くなった」「涙が止まらなかった」「目頭が熱くなった」
* **過度な偶然・都合の良い展開の禁止**
    * 「実はその人は昔の恩人だった」的な安易な展開は避ける
* **小道具・具体的描写の活用**
    * 「手紙」「写真」「手作りの品」「日記」など、物を介した感情表現を推奨

## 補足：時系列エラーの典型例と対策

### よくある失敗パターン
1. **「1年前の話」で「3年間ありがとう」**
   → 1年前に出会ったのに3年間は矛盾

2. **「2週間前」から始まって「卒業式」**
   → 2週間で卒業式は来ない

3. **「秋に手術決定」→「3ヶ月後に進級」**
   → 秋（9-11月）+ 3ヶ月 = 冬〜春（12-2月）で進級は早すぎる

### 対策
- 物語の「結末」から逆算して「冒頭の時期」を決める
- 必要な時間経過を書き出してから執筆する
- 出力前に時系列を図式化して確認する
