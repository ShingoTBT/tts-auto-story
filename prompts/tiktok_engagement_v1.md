# 【TikTok向け 共感/議論系1画像投稿プロンプト v1.0】

## 1. 目的
TikTokで「保存」「コメント」「共感」を最大限引き出す、1枚のスクリーンショット画像に収まる投稿の作成。

## 2. 投稿の要素
1. 以下のいずれかのパターンを含む
・マナーやモラルのグレーゾーン
・価値観の違いによる衝突
・人間関係での理不尽な体験
・現代の常識への疑問
・共感と反発の両方を呼ぶ行動

2. 感情表現
・絵文字を適度に使用（1〜2個程度）
・主な感情絵文字例：😅😭🤔😮‍💨💭🥺
・絵文字は文末や感情表現の直後に配置

## 3. 避けるべき要素
・犯罪的な行為 / 過度な誹謗中傷 / 明らかな差別表現 / 露骨な営業・宣伝 / 単なる愚痴 / 過度に攻撃的な内容
・実在の人物や特定できる個人を描写しない（フィクションの創作エピソードとして書く）

## 4. 文字数ルール（絶対厳守）
- **本文は200〜260文字程度に収めること。** 1枚のスクリーンショットに収まる分量。
- 1文ごとに改行し、話題の切り替わりごとに空白行を1行はさむこと。

## 5. タイトルのルール
- 17文字以内、句読点なしの体言止め、または短いフレーズ
- 内容が気になる・続きが読みたくなるフックのあるタイトルにする

## 6. 文章構成
1. 導入：状況説明（簡潔に問題提起）
2. 展開：詳細・感情（具体的なエピソード）
3. 結び：問いかけ（読者の意見を引き出す）

## 7. ハッシュタグのルール
本文の最後に、内容に関連するハッシュタグを3個つけること（多すぎても少なすぎても不可）。

## 8. 出力フォーマット（text/markdown形式で必ず出力｜考察などは不要なので本文のみを出力）

```
■(タイトルの実際の文字列。角括弧は使わない)

(本文。200〜260文字程度)
（最後に内容に合った絵文字を1〜2個）

#タグ1 #タグ2 #タグ3
■(タイトル再掲。角括弧は使わない)
```

※ブロックは1つのみ。`=====`のような区切り線は使わないこと（1枚の画像に収める投稿のため）。

## 9. 出力前の最終確認チェックリスト
- [ ] 本文は200〜260文字程度に収まっているか？
- [ ] 実在の人物や特定できる個人を描写していないか？
- [ ] タイトルは体言止め・フックのある短いフレーズか？
- [ ] ハッシュタグはちょうど3個か？
- [ ] 区切り線(`=====`)を使っていないか？
