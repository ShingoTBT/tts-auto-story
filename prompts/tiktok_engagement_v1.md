# 【TikTok向け 共感/議論系1画像投稿プロンプト v1.0】

## 1. 目的
TikTokで「保存」「コメント」「共感」を最大限引き出す、1枚のスクリーンショット画像に収まる投稿の作成。

## 2. 投稿の要素
1. 以下のいずれかのパターンを含む
・マナーやモラルのグレーゾーン
・価値観の違いによる衝突
・人間関係での理不尽な体験
・現代の常識への疑問
・共感と反発の両方を呼ぶ行動

## 2.5 【特別パターン】30代主婦×家族系の悩み×賛否両論型（時々使用）
このパターンが指定された場合、以下の型を厳密に守ること。

- **主人公**：30代（31歳、33歳など具体的な年齢）の主婦
- **テーマ**：ママ友付き合い、夫婦間の金銭・価値観のズレ、義実家との関係など、家族・ママ友がらみの悩み
- **構成**：
  1. 状況設定（主人公の年齢・立場と、相手との関係性を簡潔に）
  2. 具体的な出来事（相手からの言動、断られた・こう言われた等の具体的なやり取り）
  3. 追加の一撃（さらに追い打ちをかける第三者の発言。特に「夫」や「義母」など身近な人物からの、突き放すような発言を入れると効果的）
  4. 自分の本音・言い分（正直な気持ちを吐露する）
  5. **相手側の言い分にも理解を示す一文を入れる（読者の意見が割れるように、あえて自分だけが正しいと決めつけない）**
  6. **締めは「皆さんはどちらの言い分が正しいと思いますか？」のように、読者に二択で意見を求める、直接的な問いかけで終える**（このパターンに限っては、直接的な呼びかけ調で良い）
- **文体**：淡々と事実を述べる客観的なトーン。感情的になりすぎず、読者が自分で判断できるだけの情報を淡々と積み重ねる書き方にする。
- **注意**：このパターンを使う場合も、全体の文字数・タイトル・2ブロック構成（`=====`区切り）・ハッシュタグ3個などの基本フォーマットは変更しないこと。上記の1〜6の流れを、2ブロックの中に自然に収めること。

2. 感情表現
・絵文字を適度に使用（1〜2個程度）
・主な感情絵文字例：😅😭🤔😮‍💨💭🥺
・絵文字は文末や感情表現の直後に配置

## 3. 避けるべき要素
・犯罪的な行為 / 過度な誹謗中傷 / 明らかな差別表現 / 露骨な営業・宣伝 / 単なる愚痴 / 過度に攻撃的な内容
・実在の人物や特定できる個人を描写しない（フィクションの創作エピソードとして書く）

## 4. 文字数ルール（絶対厳守）
- **全体で320〜380文字程度に収めること。** 2枚のスクリーンショットに均等に収まる分量。
- **2ブロック構成にすること。** 1ブロックあたり160〜190文字程度で均等に分ける。
- ブロック間は必ず `=====` で区切ること。
- 1文ごとに改行し、話題の切り替わりごとに空白行を1行はさむこと。

## 5. タイトルのルール
- 17文字以内、句読点なしの体言止め、または短いフレーズ
- 内容が気になる・続きが読みたくなるフックのあるタイトルにする

## 6. 文章構成
1. 第1ブロック：導入・状況説明（簡潔に問題提起、具体的なエピソードの始まり）
2. 第2ブロック：展開・結び（感情の高まり、問いかけで締める）

## 7. ハッシュタグのルール
本文の最後に、内容に関連するハッシュタグを3個つけること（多すぎても少なすぎても不可）。

## 8. 出力フォーマット（text/markdown形式で必ず出力｜考察などは不要なので本文のみを出力）

```
■(タイトルの実際の文字列。角括弧は使わない)

(第1ブロック。160〜190文字程度)

=====

(第2ブロック。160〜190文字程度)
（最後に内容に合った絵文字を1〜2個）

#タグ1 #タグ2 #タグ3
■(タイトル再掲。角括弧は使わない。ハッシュタグ行の直後に空白行を入れず、必ず次の行に続けて書くこと)
```

※出力全体をMarkdownのコードブロック（```で囲む）にしないこと。本文をそのまま出力すること。

## 9. 出力前の最終確認チェックリスト
- [ ] 全体で320〜380文字程度に収まっているか？実際に文字数を数えたか？短ければ、具体的な描写やセリフを1〜2文追加すること（削って調整するのではなく、加筆で目標文字数に届かせる）
- [ ] 2ブロックの文字数バランスは均等か？
- [ ] 実在の人物や特定できる個人を描写していないか？
- [ ] タイトルは体言止め・フックのある短いフレーズか？
- [ ] ハッシュタグはちょうど3個か？
- [ ] 区切り線(`=====`)が1つだけ含まれているか？

## 10. 分量の目安（重要）
以下は約350文字の例です。これより短くならないように意識してください。

```
■結婚式のご祝儀トラブル

友人の結婚式に招待されて、ご祝儀3万円を包んで出席した。

料理は立食のビュッフェで、正直かなりこじんまりしてた。
式の最後に新婦から「今日の食事代は実費でお願いします」って封筒を渡された。

え、ご祝儀とは別に？と思いながら開けたら5000円の請求書。

=====

「会場費の関係でどうしてもお願いしたくて」って言われたけど、それならそもそも招待しないでほしかった。

祝う気持ちはあったけど、さすがにこれはモヤった😮‍💨

招待された側が当日に追加請求されるのって普通なのかな？
それとも私の金銭感覚がズレてる？

みんなはどう思う？💭

#結婚式 #ご祝儀問題 #人間関係
```

## 重要：出力に関する絶対禁止事項
- 文字数確認・自己チェックの結果・「✅」「❌」などのマーク・[info]や[note]のようなタグ・メタ情報を、出力に一切含めないこと。
- 出力は、実際にSNSへそのまま投稿される本文そのものである。チェックは内部で行い、その結果や過程を書き残さず、最終的な投稿本文だけを出力すること。
