# 【TikTok向け 共感/議論系1画像投稿プロンプト v1.0】

## 1. 目的
TikTokで「保存」「コメント」「共感」を最大限引き出す、1枚のスクリーンショット画像に収まる投稿の作成。

## 2. 投稿の要素
1. 以下のいずれかのパターンを含む
・マナーやモラルのグレーゾーン
・価値観の違いによる衝突
・人間関係での理不尽な体験
・現代の常識への疑問
・共感と反発の両方を呼ぶ行動

2. 感情表現
・絵文字を適度に使用（1〜2個程度）
・主な感情絵文字例：😅😭🤔😮‍💨💭🥺
・絵文字は文末や感情表現の直後に配置

## 3. 避けるべき要素
・犯罪的な行為 / 過度な誹謗中傷 / 明らかな差別表現 / 露骨な営業・宣伝 / 単なる愚痴 / 過度に攻撃的な内容
・実在の人物や特定できる個人を描写しない（フィクションの創作エピソードとして書く）

## 4. 文字数ルール（絶対厳守）
- **全体で320〜380文字程度に収めること。** 2枚のスクリーンショットに均等に収まる分量。
- **2ブロック構成にすること。** 1ブロックあたり160〜190文字程度で均等に分ける。
- ブロック間は必ず `=====` で区切ること。
- 1文ごとに改行し、話題の切り替わりごとに空白行を1行はさむこと。

## 5. タイトルのルール
- 17文字以内、句読点なしの体言止め、または短いフレーズ
- 内容が気になる・続きが読みたくなるフックのあるタイトルにする

## 6. 文章構成
1. 第1ブロック：導入・状況説明（簡潔に問題提起、具体的なエピソードの始まり）
2. 第2ブロック：展開・結び（感情の高まり、問いかけで締める）

## 7. ハッシュタグのルール
本文の最後に、内容に関連するハッシュタグを3個つけること（多すぎても少なすぎても不可）。

## 8. 出力フォーマット（text/markdown形式で必ず出力｜考察などは不要なので本文のみを出力）

```
■(タイトルの実際の文字列。角括弧は使わない)

(第1ブロック。160〜190文字程度)

=====

(第2ブロック。160〜190文字程度)
（最後に内容に合った絵文字を1〜2個）

#タグ1 #タグ2 #タグ3
■(タイトル再掲。角括弧は使わない。ハッシュタグ行の直後に空白行を入れず、必ず次の行に続けて書くこと)
```

※出力全体をMarkdownのコードブロック（```で囲む）にしないこと。本文をそのまま出力すること。

## 9. 出力前の最終確認チェックリスト
- [ ] 全体で320〜380文字程度に収まっているか？実際に文字数を数えたか？短ければ、具体的な描写やセリフを1〜2文追加すること（削って調整するのではなく、加筆で目標文字数に届かせる）
- [ ] 2ブロックの文字数バランスは均等か？
- [ ] 実在の人物や特定できる個人を描写していないか？
- [ ] タイトルは体言止め・フックのある短いフレーズか？
- [ ] ハッシュタグはちょうど3個か？
- [ ] 区切り線(`=====`)が1つだけ含まれているか？

## 10. 分量の目安（重要）
以下は約350文字の例です。これより短くならないように意識してください。

```
■結婚式のご祝儀トラブル

友人の結婚式に招待されて、ご祝儀3万円を包んで出席した。

料理は立食のビュッフェで、正直かなりこじんまりしてた。
式の最後に新婦から「今日の食事代は実費でお願いします」って封筒を渡された。

え、ご祝儀とは別に？と思いながら開けたら5000円の請求書。

=====

「会場費の関係でどうしてもお願いしたくて」って言われたけど、それならそもそも招待しないでほしかった。

祝う気持ちはあったけど、さすがにこれはモヤった😮‍💨

招待された側が当日に追加請求されるのって普通なのかな？
それとも私の金銭感覚がズレてる？

みんなはどう思う？💭

#結婚式 #ご祝儀問題 #人間関係
```
